# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/rtorcato/shared-docs/security/advisories/new).

You can expect an acknowledgement within 7 days and a status update within 14 days.

## Supported versions

Only the latest published release of `@rtorcato/shared-docs` receives fixes.
